Introdução ao Git & GitHub

Módulo I - Introdução ao Git

O Git não serve apenas para código, mas também para rastrear a evolução de qualquer arquivo de texto ao longo do tempo.

Controle de versão

O controle de versão é o mecanismo que permite rastrear as alterações em um arquivo ou conjunto de arquivos ao longo do tempo, saber quem fez, quando, por que e como restaurar uma versão anterior.

Colaboração

A colaboração permite que vários programadores trabalhem juntos em um código, mesmo que estejam geograficamente dispersos. Isso possibilita uma divisão de tarefas mais eficiente e facilita a resolução de problemas complexos.

Benefícios do controle de versão e da colaboração

  • Histórico completo de alterações
  • Rastreamento de responsabilidades e contribuições individuais
  • Recuperação rápida de versões anteriores
  • Paralelismo de desenvolvimento
  • Aumento da transparência

Ferramentas de controle de versão anteriores ao Git

  • CVS
  • SVN
  • Mercurial

Diferenças entre Git e GitHub

O Git é um sistema de controle de versão, onde você gerencia seu código localmente.

O GitHub é uma plataforma na nuvem que utiliza o Git para hospedar projetos de software e permite compartilhar e colaborar online.

Alternativas ao GitHub

  • GitLab
  • Bitbucket
  • Azure DevOps
